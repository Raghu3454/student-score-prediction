# Student Score Prediction using Machine Learning

## 📌 Project Overview

This project predicts a student's exam score based on the number of hours they studied.
It uses **Linear Regression**, a simple machine learning algorithm, to learn the relationship between study hours and exam scores.

This is a beginner-friendly **Machine Learning project using Python and Scikit-learn**.

---

## 🎯 Objectives

* Predict student exam performance
* Understand Linear Regression
* Learn how to train a machine learning model
* Practice working with datasets using Python

## 📊 Dataset

The dataset contains two columns:

| Column | Description             |
| ------ | ----------------------- |
| Hours  | Number of hours studied |
| Score  | Student exam score      |

Example dataset:

```id="s1p2"
Hours,Score
1,20
2,25
3,35
4,45
5,55
6,60
7,70
8,80
```

## ▶️ How to Run the Project

Run the Python script:

```id="s1p4"

```

Then enter the number of study hours.

Example:

```id="s1p5"

Predicted Score: 56.3
```

---

## 🧠 Machine Learning Workflow

1. Load dataset using Pandas
2. Separate input (Hours) and output (Score)
3. Train Linear Regression model
4. Predict exam score for given study hours
